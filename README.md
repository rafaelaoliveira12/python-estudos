# 🐍 Projetos em Python

Repositório com meus primeiros projetos desenvolvidos em Python, durante meus estudos em programação.

## 📂 Projetos

### 🧮 Calculadora de IMC
Calcula o Índice de Massa Corporal com base no peso e altura informados, classificando o resultado.

**Conceitos aplicados:** funções, condicionais, tratamento de exceções, loops, validação de dados.

📄 [imc.py](./imc.py)

---

### ✖️ Tabuada
Gera a tabuada de qualquer número de 1 a 10.

**Conceitos aplicados:** funções, laços de repetição (`for`), menus interativos.

📄 [tabuada.py](./tabuada.py)

---

### ➕ Calculadora Básica
Realiza operações matemáticas básicas: soma, subtração, multiplicação e divisão.

**Conceitos aplicados:** funções, condicionais, tratamento de exceções, validação de divisão por zero.

📄 [calculadora.py](./calculadora.py)
